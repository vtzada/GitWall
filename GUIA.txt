# REQUISITOS DO SISTEMA DE TEMAS

Não faça algo como:

```tsx
if (theme === "github") {
   ...
}

if (theme === "dracula") {
   ...
}

if (theme === "tokyo") {
   ...
}
```

espalhado por vários componentes.

Crie uma abstração simples e tipada.

Exemplo conceitual:

```ts
type ThemeId =
  | "github"
  | "dracula"
  | "tokyo-night"
  | "monochrome"
  | "amber-flame";
```

E um registry:

```ts
const themes: Record<ThemeId, HeatmapTheme> = {
   ...
};
```

A implementação deve ser simples.

**Não crie uma arquitetura de design system desnecessária.**
